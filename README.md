# 📊 E-Commerce Sales Analysis

## 📌 Project Overview
This project analyzes e-commerce sales data using Python. It provides insights into sales, profit, monthly trends, and regional performance using different charts.

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib

## 📈 Features
- Total Sales Analysis
- Total Profit Analysis
- Sales by Category (Bar Chart)
- Profit by Category (Pie Chart)
- Monthly Sales Trend (Line Chart)
- Sales Distribution (Histogram)
- Region-wise Sales Analysis
